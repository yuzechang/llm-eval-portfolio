# 大模型测试工程师培训包

> 面向传统软件测试工程师的「AI 测试 / 大模型测试 / LLM 评测」转型培训方案。
> 目标:在职每天 3 小时、约 15 周,达到「中级(初到中)评测工程师」水平,能直接入职并胜任工作。

## 核心定位

- **简历定位**:AI 应用 QA(接口测试切入)+ LLM 评测知识
- **主线项目**:API 文档智能问答助手 + 评测体系(RAG 评测核心技能全覆盖)
- **辅助项目**:LLM 生成接口测试用例的质量评测(AI 测试提效方向)
- **最终成果**:GitHub 开源项目,可直接放简历

| `scripts/` | 环境搭建脚本 + 样例代码脚手架(待生成) |

## 使用方式

1. 从 `01_培训总方案.md` 开始,按周推进
2. 每周五往 GitHub 仓库 push 产出物(作品集就是学习产出)
3. 每个阶段结束对照 `06_阶段检验清单.md` 自检,不达标不进入下一阶段
4. 第 8 周起同步开始投递简历,用面试反馈校准后续学习

## 周期测算前提

- 在职学习,每天 3 小时
- 已有 Python / 接口测试 / 数据库 / 自动化脚本基础
- 总周期约 15 周(约 3.5 个月)
